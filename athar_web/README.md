# ATHAR (أثر)

ATHAR is a web system that predicts antibiotic resistance in *Escherichia coli* from a MALDI-TOF mass
spectrum. It takes the preprocessed DRIAMS-style spectrum (6,000 bins of 3 Da, 2,000–20,000 Da) and
returns, for each antibiotic with an installed model, a resistance call, the regions of the spectrum that
drove it, and candidate proteins for those regions. Research use only: ATHAR does not replace
phenotypic antimicrobial susceptibility testing.

## What it does

| Page | Purpose |
| --- | --- |
| Analyze (`/`) | Upload a spectrum with a sample ID and species. Non-*E. coli* species are refused. |
| Results (`/analysis/<n>`) | Call, score and threshold per antibiotic; the spectrum with the model's regions shaded; the effect of each region on this call; candidate proteins with UniProt, AlphaFold and BLAST links. |
| Report (`/analysis/<n>/report`) | One-page printable report with a review section. Print or save as PDF from the browser. |
| Antibiotics (`/antibiotics`, `/antibiotic/<name>`) | Drug class, WHO AWaRe group, links to PubChem, KEGG, CARD, EUCAST and WHO; the installed model and its regions. |
| History (`/history`) | All analyses, searchable, with CSV export. |
| About (`/about`) | Data, how a prediction is made, installed models. |
| API (`/docs`) | Interactive documentation of the REST API, generated by FastAPI. |

## Run it

From the repository root, with the project's virtual environment active:

```powershell
pip install -r requirements.txt
python -m uvicorn athar_web.main:app --reload
```

Open http://127.0.0.1:8000. Stop the site with Ctrl+C.

## Install the prediction models

The final models are exported by `export_athar_models.py` (repository root) into `models/athar/`. Install
them into ATHAR with:

```powershell
python -m athar_web.tools.install_models "<spectra folder>" data/labels_ecoli_A_corrected.csv models/athar
```

This writes one folder per antibiotic into `athar_web/models/`, computes the 2015–2017 average of each
model bin (used for the explanations) and checks that ATHAR reproduces the exported scores exactly.
The registry format is in [`models/README.md`](models/README.md). Restart the site after adding or replacing a model. An antibiotic
without a model is shown as "Not installed" and skipped during analysis.

## Score the installed models on the 2018 test set (once)

```powershell
python -m athar_web.tools.evaluate_installed_models "<spectra folder>" data/labels_ecoli_A_corrected.csv
```

Scores each installed model once on the 2018 spectra (threshold fixed on 2015–2017), adds the test metrics
to each `model.json`, and writes `results/athar_test_eval/test_metrics.csv` and `test_predictions.csv`.
Run it again after re-installing the models.

## Build the protein table (once)

```powershell
python -m athar_web.tools.build_protein_table
```

Queries UniProtKB for reviewed *E. coli* K-12 proteins in each of the 600 m/z regions (as [M+H]+, with
and without the first methionine) and writes `athar_web/data/uniprot_candidates.csv`. It needs internet,
takes 10–20 minutes, and does not depend on the model. Commit the CSV so the site works offline.

## Change the example spectrum

```powershell
python -m athar_web.tools.export_example_spectrum "<spectra folder>" --index 0
```

Writes `static/data/representative_spectrum.json`, used by the home-page trace and the
"Use an example spectrum" button.

## Explanations

For each region a model uses, ATHAR replaces those 10 bins with their average over the training spectra
and scores the sample again. The difference between the two scores is the region's effect on the call:
positive values pushed the score towards resistant, negative values towards susceptible. For PCA models
the same is done per component.

## Tests

```powershell
pip install pytest httpx
python -m pytest athar_web/tests -q
```

The tests build dummy models from random data in a temporary folder, so they never touch the real
models or the history database.

## Files

| Path | Content |
| --- | --- |
| `main.py` | FastAPI app: pages and API |
| `registry.py` | Loads the models, scores spectra, computes explanations |
| `predict.py` | Checks and reads an uploaded spectrum file |
| `history_db.py` | SQLite history (sample ID, file name, spectrum, calls; no patient data) |
| `proteins.py` | m/z region to candidate protein lookup and links |
| `knowledge.py` | WHO AWaRe groups and outside links per antibiotic |
| `spectrum_trace.py` | Draws spectrum traces as SVG |
| `templates/`, `static/` | Pages, styles, scripts, fonts, Plotly |
| `tools/` | Model installer, test-set evaluation, protein table and example spectrum builders |
| `tests/` | Automated tests |

Environment variables: `ATHAR_MODELS_DIR` points to another models folder, `ATHAR_DB_PATH` to another
history database. Both are optional.
